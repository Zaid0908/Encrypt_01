## `// INSTALLATION`

### Requirements

* Python 3.x
* Tkinter
* Pillow
* Cryptography

Install dependencies:

```bash
pip install pillow cryptography
```

### Clone Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

### Launch

```bash
python Encrypt_Data.py
```
